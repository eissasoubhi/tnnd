Tinder auto-chat

Conversation Flow is a suggestion based on saved chat history and known facts, never a fixed questionnaire. The match’s reply always comes first. Your Extra instructions and per-chat instructions remain in effect.

Incoming replies use the reply-delay window (default 20–60 seconds). Opening bubbles now use an estimated typing time for the next message: a word or two usually takes 1–3 seconds; longer sentences take longer. The fast/slow settings describe the time to type about 60 characters (default 8–15 seconds), not a fixed minimum gap or maximum for every bubble. Previously saved values are safely adjusted to a realistic pace. The delay between conversations is configured separately.

What counts? One opener attempt for an eligible match counts once, even if it contains several bubbles. This cap is shared by manual single-chat starts, already-existing empty matches and future matches, not five messages to the same conversation. Attempts with uncertain delivery also count to prevent accidental retries. The quota resets at 00:00 UTC; it does not permit sending another opener to the same previously attempted match the next day. Replies to incoming messages use the separate automatic-replies limit. TNND replies only when the latest detected Tinder message is incoming and will not automatically retry an unconfirmed send.
